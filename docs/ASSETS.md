# 图片与素材授权清单

本项目共使用 36 张实景照片，全部来自 Wikimedia Commons，按 CC0 / CC BY / CC BY-SA / 公有领域授权使用。

统一处理：等比裁切至 3:2、缩放到 640 px 宽、WebP 重编码（单张 ≤20 KB），并以内联 data URI 嵌入页面，运行时不产生任何外部图片请求。

> 许可字段依各文件页整理；CC BY 与 CC BY-SA 需保留署名，页面内每张图下方已显示来源与许可。若要逐张核对，可用下表的地点与建筑名在 Commons 检索原文件。
